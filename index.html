Stillwater

Deeper surfaces. Richer color. Room to think.

An indigo-slate ground, darker than Nord or Dracula, with periwinkle, orchid, and frost accents at different depths. Made for coding, terminals, and agent sessions, with one loud thing on screen: the cursor.

A place for every color

Nord × Dracula

The room is shared. The ground is darker than either parent, with their low chroma and a hue between them. Soft white text stays clear of pure white glare.

The color is borrowed. ANSI blue turns periwinkle and magenta turns orchid, the same move Dracula makes, with about a fifth less chroma. Cyan stays close to Nord’s frost.

Depth does the sorting. Accents sit at different lightness levels, so they stay apart when hue is hard to see. The orchid cursor is the one thing meant to stand out.

Surfaces & text

All 16 ANSI colors

Normal colors 0–7; bright colors 8–15. Each sample includes its index and exact hex value. “Bright black” doubles as the suggested comment color.

A terminal palette supplies colors, not syntax rules. To get these comments in an editor or agent, select ANSI 8 or set its comment color to #9da5bf. Explicit truecolor output can ignore the palette.

Quiet does not mean faint

These checks use WCAG’s sRGB relative luminance formula. 4.5:1 is the reference for normal text; 7:1 is the enhanced threshold. Results use opaque colors, not a transparent terminal window.

Colors that stay apart

Contrast only compares a color with its background. This table compares accents with each other, in normal vision and in simulated color-vision deficiency.

Known limits. ANSI 0 is a surface color, not readable text on this background. Green and yellow stay close under protanopia. Dim text falls below 4.5:1 because the terminal fades it, and no comment color can fix that while staying quieter than body text; the 50% figure is an estimate, and terminals differ. A passing ratio does not prove comfort over a long session.

Between its parents

The same code on Nord, Stillwater, and Dracula, each on its own ground. A real blend should read as related to both and be mistaken for neither.

Parent values come from the Nord and Dracula themes bundled with Ghostty. Lightness and chroma are OKLCH.

Install Stillwater

The theme file uses Ghostty’s format and sets terminal colors only. It leaves fonts, opacity, and key bindings alone.

Save Stillwater Ghostty theme file

Ghostty

Copy the file into your themes folder, then add theme = Stillwater to your Ghostty config.

mkdir -p ~/.config/ghostty/themes
cp themes/Stillwater ~/.config/ghostty/themes/

Rex

Find your app’s label with rex client ls, then run this from the project directory. Importing also selects the theme, so note your current one first. To switch back, use Change Theme… in the command palette.

rex -C CLIENT do client.theme.import path="$PWD/themes/Stillwater"

This guide is an HTML approximation of a terminal. Editor themes, agent truecolor output, font rendering, and app chrome can differ.
